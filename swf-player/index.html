Games that load extra files (data/, sound/ …) need the whole folder: zip it in the Files app (long-press → Compress) and open the ZIP.

Only for a single SWF whose extra files (data/, sound/ …) are hosted on a website: paste that folder's URL here before tapping Open a file. Leave it empty for everything else.
